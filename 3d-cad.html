HƯỚNG DẪN KỸ THUẬT & TÀI LIỆU CAD

Nguồn Tải File 3D CAD Máy CNC & Quy Trình Triển Khai Với Spline (spline.design)

Tổng hợp chi tiết các thư viện CAD máy công cụ CNC thế giới và quy trình chuyển đổi đưa vào web.

1. GrabCAD Community

Kho lưu trữ CAD cơ khí lớn nhất thế giới. Hàng ngàn kỹ sư chia sẻ miễn phí file lắp ráp hoàn chỉnh của máy phay CNC (VMC-850, Haas VF-2, Brother, Mazak) ở định dạng chuẩn STEP (.stp) và SolidWorks (.sldasm).

Tìm CAD CNC trên GrabCAD →
2. McMaster-Carr & TraceParts

Nguồn tải file 3D CAD chuẩn xác 100% của từng mã phụ tùng: Ray trượt tuyến tính THK/Hiwin, trục vitme bi mài C3/C5, cụm gối đỡ BK/BF, và bầu kẹp dao BT30/BT40.

Tải CAD phụ tùng chuẩn →
3. Sketchfab (Web-Ready 3D)

Nguồn tải các mô hình máy CNC đã được tối ưu hóa số lượng đa giác (Low-poly / Mid-poly) sẵn định dạng GLTF (.glb) và OBJ, có thể kéo thả thẳng vào Spline mà không cần giảm dung lượng.

Tìm mô hình trên Sketchfab →

Quy Trình 4 Bước Đưa File 3D CAD Vào Spline.design

BƯỚC 01
Tải File CAD (.STEP)

Tải cụm lắp ráp máy CNC hoặc trục chính Spindle từ GrabCAD hoặc xưởng thiết kế.

BƯỚC 02
Chuyển Sang .OBJ / .GLB

Vì Spline là công cụ Web polygon (không đọc trực tiếp file tham số .STEP), mở file bằng Blender/FreeCAD và bấm Export sang .OBJ hoặc .GLTF.

BƯỚC 03
Thiết Lập Trên Spline

Kéo thả file vào app.spline.design. Đặt chất liệu Wireframe phát sáng cam hoặc kim loại PBR. Tạo State di chuyển các linh kiện bung ra khi User cuộn chuột.

BƯỚC 04
Xuất Mã Nhúng Web

Nhấn nút Export → Viewer URL hoặc dùng thẻ nhúng <spline-viewer> dán vào HTML.

// Cách nhúng Spline vào website HTML với 2 dòng:
<script type="module" src="https://unpkg.com/@splinetool/viewer/build/spline-viewer.js"></script>
<spline-viewer url="https://prod.spline.design/YOUR_SCENE_ID/scene.splinecode"></spline-viewer>
