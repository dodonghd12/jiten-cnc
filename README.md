## 🌟 Tính Năng Nổi Bật
- **Thiết Kế Đẳng Cấp Anti-AI Slop**: Phong cách tối giản kỹ thuật cao lấy cảm hứng từ **ZEGGO (Singapore Tech)** và **Oryzo.ai**.
- **Không vỡ font Tiếng Việt**: Chuẩn hóa typography với bộ font Google `Be Vietnam Pro` + `Inter` + `JetBrains Mono`.
- **Cuộn Chuột Kỹ Thuật Số (Scroll Storytelling)**: Tích hợp `Lenis Smooth Scroll` + `GSAP ScrollTrigger` đồng bộ tiến trình qua 4 trụ cột năng lực.
- **Hình Ảnh Máy Móc Thực Tế**: Sử dụng ảnh xưởng máy thật tại Trảng Bom, Đồng Nai.
- **Bảng Tra Cứu Thông Số (Catalog Matrix)**: Lọc động các dòng máy Phay VMC, Tiện CNC, Cắt dây EDM.
- **Form Báo Giá Kỹ Thuật (RFQ)**: Hỗ trợ kéo thả đính kèm bản vẽ định dạng `STEP`, `DWG`, `DXF`, `PDF`.
- **Triển Khai Serverless Siêu Tốc**: Tương thích hoàn hảo với GitHub Pages và Cloudflare Pages Edge CDN.

- **Cloudflare Pages**: Kết nối trực tiếp với repo này để có domain `*.pages.dev` với băng thông không giới hạn và SSL tự động.
